## 👋 About

This repository contains my personal portfolio website, built to present my projects, skills, certificates, achievements, and professional links in a responsive web interface.

I enjoy learning by building practical projects and continuously improving my skills in web development and programming.

## ✨ Highlights

- 📱 Responsive interface for desktop and mobile
- 🌙 Dark / light mode with localStorage
- 🎨 Custom CSS animations and transitions
- 🧩 Project and skills showcase
- 📜 Certificate gallery
- 🔎 Basic SEO support with `robots.txt` and `sitemap.xml`
- 🔗 Integrated professional and contact links
- 📬 Ticket form via Formspree

## 🛠️ Tech Stack

| Technology   | Usage                                          |
| ------------ | ---------------------------------------------- |
| HTML5        | Semantic page structure                        |
| CSS3         | Layout, styling, responsiveness and animations |

## 🚀 Run Locally

Clone the repository and open the project locally:

```bash
git clone https://github.com/MozafariDev/MozafariDev.github.io.git
cd MozafariDev.github.io
```

Then open `index.html` in a modern browser.
